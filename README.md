# Exercícios de Python

Exercícios acadêmicos desenvolvidos durante a graduação em Análise e Desenvolvimento de Sistemas no CEUB.

## Conteúdo

| Arquivo | Objetivo |
| --- | --- |
| [`sequence_ascending.py`](./sequence_ascending.py) | Exibir uma sequência crescente e contar seus elementos. |
| [`sequence_descending.py`](./sequence_descending.py) | Exibir uma sequência decrescente até zero. |
| [`sum_1_to_500.py`](./sum_1_to_500.py) | Somar os números de 1 a 500 usando repetição. |
| [`sum_arithmetic_progression.py`](./sum_arithmetic_progression.py) | Somar uma sequência iniciada em 3 com incremento de 6. |

## Conceitos praticados

- Entrada e saída de dados
- Variáveis
- Estruturas de repetição com `while`
- Contadores e acumuladores

## Executar

Tenha o Python 3 instalado e execute o arquivo desejado:

```bash
python sequence_ascending.py
```
